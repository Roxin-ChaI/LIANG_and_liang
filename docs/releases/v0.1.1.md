# LIANG & liang v0.1.1

本版整合 v0.1.0 之后的全部提交历史，将审核完成的 Gu / Feng Look 修复接入独立 macOS App。修复覆盖全部 16 个观察方向，保持 192×208 单帧与原有动作映射。

## 素材修复

- **Gu Look**：清理颈部残留和浅色背景下的白边；恢复颈部连接，修复抠图后出现的透明断口。
- **Feng Look 颈部**：清理抠图残留并保留方向性阴影；修复向左下观察时右侧颈部透明缺口。
- **Feng Look 眼镜**：补全向右下观察时镜框 / 镜片断边，保持已存在的脸部像素。
- **Feng Look 手腕与袖口**：连接方向性手部与袖口，保留已修复的肩膀和西装配色。
- **Feng Look 袖口与衬衣分层**：固定胸前衬衣纹理，以原有深蓝与暗色像素区分前景袖口，减少布料被一起拉扯的观感。

## 正式接入与构建

- 新正式选择位于 `assets/releases/v0.1.1/gu.webp`、`feng.webp`；`manifest.json` 记录输入来源和 SHA256。
- 仅替换两套图集的 Look 行（零起始第 9 / 10 行），其余动作逐像素保持 v0.1.0 已选素材；双向变身文件不变。
- App 内版本、macOS Bundle 版本统一为 0.1.1。
- 保留全部开发提交及失败候选以供追溯；明确否决的上半身恢复方案不进入发布图集。
- 不修改 Codex 安装包、已授权 Hook、生产 Codex 配置、播放器或时间调度行为。

## 验证范围

- 109 项相关 Python 回归通过，包括素材保护区域、Look 逐帧精确接入、其他动画行保持及打包选择。
- 独立 App 全部 43 项 Node 回归通过。
- 打包内全部 43 个输入文件与当前选定来源哈希一致；版本一致性及严格 ad-hoc 签名校验通过。

这不是全部历史 Python 测试通过声明。模拟交互及测试时钟不代表重新验收真实 Desktop Hook 事件或实体鼠标手感。

## 已知限制

- 手动选择形态不是固定模式：调度器仍按北京时间工作日 09:00–12:00、14:00–18:00 校正为 Feng，其他时间为 Gu。
- 本机 macOS 构建使用 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；不应关闭系统安全机制。
- 构建仍保留本机路径依赖，尤其可选 Hook 接收器与 Python 环境，不是通用安装器。首次启用 Hook 仍需要检查路径及人工信任授权。
- 既有工作动画半透明像素及额外未使用 Idle 槽沿用 v0.1.0，没有在本次 Look 修复中更改。
- 冻结标准 atlas 与历史修复候选保留原文件；运行选择以 `standalone-app/asset-overrides.json` 为准。

## 使用

本机正式 App 路径：`dist/Liang no Henshin.app`。旧包备份另存，避免重复启动多个桌宠及接收器。
发行包中的 ZIP 为本次本机架构构建，附 SHA256 清单；源码构建步骤见 `standalone-app/README.md`。
