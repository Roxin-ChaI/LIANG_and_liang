# LIANG & liang v0.1.0

首个独立 macOS 桌宠开发版本：梁文谷（Gu）与梁文峰（Feng）双形态、像素动画、变身和北京时间峰谷调度。

## 功能

- 独立 Electron 透明桌宠窗口，可悬停、拖动及通过右键选择工作状态和形态；不修改 Codex 安装包。
- Gu / Feng 双形态，使用 192×208 单帧的 v2 图集。
- Gu→Feng 10 帧、Feng→Gu 8 帧变身，变身结束恢复当前工作状态。
- 北京时间工作日 09:00–12:00、14:00–18:00 为 Feng，其余时间为 Gu；支持启动校正和休眠恢复。
- 保留已验证的 Codex Desktop Hook 适配：SessionStart、PreToolUse、PostToolUse、Stop。部署 Hook 需要本机路径配置及人工信任授权，不默认启用未经验证的事件。

## 本版素材更新

- Gu 左右悬吊轻摆各 8 帧。
- Feng 右行 8 帧及逐帧镜像的左行 8 帧。
- Feng Failed 点头/握拳修订版。
- Feng Waving、Review 白边清理版。
- 已批准像素原样接入；播放时长与审核预览匹配。
- Feng Look 保留现有运行版本，不包含尚未完成的 16 方向返工。

## 验证

- 108 项相关 Python 回归通过；独立 App 全部 43 项 Node 测试通过。不是整个历史 Python 测试集的全通过声明。
- 实际启动打包后的 Electron App，七项更新动作均观察到完整帧索引。
- 双向变身 10 / 8 帧、状态恢复、注入时钟边界、重启校正及透明窗口截图通过。
- 新包实体鼠标手感及真实 Codex Hook 端到端联动尚需用户复验；隔离验收使用测试事件，不冒充真实 Desktop 事件。

## 已知限制

- 手动选择 Gu / Feng **不是固定模式**。调度器每隔最多 60 秒、App 激活或系统唤醒时会按北京时间校正形态；周末手动选择 Feng 后会回到 Gu。
- Feng Look 剩余方向返工暂缓；旧运行素材未修改。
- 部分获批动作仍保留已记录的比例/高度差异，不代表所有历史视觉问题已修复。
- Gu Waiting / Running / Review 的既有半透明像素及图集额外 Idle 槽原样保留。
- 当前版本面向已验证的本机 macOS 环境，包含本机路径假设；不是经过通用安装、自动启动或跨平台验收的正式安装器。
- 本地 App 为 ad-hoc 签名，未做 Apple Developer ID 签名或公证。不要为运行本版本关闭系统安全机制。
- 旧 `runtime-patch/` 与诊断历史仅供追溯；当前独立 App 不需要修改、注入或重签 Codex。

## 使用与构建

构建及运行说明见 `standalone-app/README.md`。源码不包含 Electron 的 `node_modules`、Python 虚拟环境或本机配置，需先按项目依赖清单准备环境。

首次试用请先正常退出旧桌宠，避免重复窗口和 Hook 接收器争用。右键可以选择形态、工作状态和退出。所有新素材审核记录与验收范围保留在 `docs/approved-actions-integration-2026-10-23.md`。
