# macOS Code Signing Trust Diagnosis

This document is generated by `tools/diagnose_macos_trust.py` during Phase 8A.

The diagnostic is read-only. It inspects code-signing structure, designated
requirements, embedded certificate chains, certificate dates, trust settings,
root availability, Gatekeeper results, trust services, and a bounded set of
recent trust-related errors. It does not modify applications, keychains, trust
settings, Gatekeeper, security services, or system policy.

System measurements and the Phase 8 gate decision will replace this template
only after the diagnostic tests pass.
