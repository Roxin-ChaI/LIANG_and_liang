# Feng Look：完整上半身连接恢复候选

状态：**PENDING_USER_REVIEW**。不安装、不替换当前 App、不发布。

## 这次改了什么

上版只恢复了方向手掌/袖口，仍把它拼到固定正面前臂、肩部和领口上。
该错误不能靠证明手掌像素来自原图来排除：手掌以外的连接处仍然来自不同姿势。

此次撤销这部分混合：按原方向恢复原 atlas 的 y=45..89 完整区域。
头部 y<45 和身体 y>=90 不改；y=86..93 是两份素材逐像素一致的接回带。
没有缩放、重绘、插值、补色或调整坐标。

**结果与原始 atlas 的对应 Look cell 完全一致。** 这是恢复被旧 compositor
破坏的原有连接，不是声称生成了新的更优素材。原始素材路径为
`assets/builds/feng/spritesheet.webp`，文件本身没有修改。

## 自检与限制

- 已查看 16 个方向的四页上半身对照，检查手掌、袖口、前臂、领口和肩部；
  不再使用之前穿过这些部位的局部矩形补丁。
- 验证方向顺序、上下受保护区域、相同接回带、RGBA/二值 alpha、透明 RGB 清零。
- 完整下半身仍逐像素固定，脚底 y=203。
- 原素材中肩膀/领口随方向的变化被保留，因此**不再声称上半身逐像素固定**。
- 自动测试只证明来源、连接边界和不变区域，不证明人体结构或动画美观。
- 原素材自身的姿态跳变、轮廓与边缘问题仍需视觉审批；不标记整体视觉 PASS。
- 未进行 App 真机验收，未修改正式图集、Gu、播放器或当前安装包。
